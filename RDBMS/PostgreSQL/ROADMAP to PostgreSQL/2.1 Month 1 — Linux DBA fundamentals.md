           - Directories
            
              | Windows                            |                                 Linux |
              | ---------------------------------- | ------------------------------------: |
              | Multiple drives (`C:`, `D:`, `E:`) | Single directory tree starting at `/` |
              | `C:\Program Files`                 |                        `/usr`, `/opt` |
              | `C:\Users\John`                    |                          `/home/john` |
              | `C:\Windows\System32`              |           `/bin`, `/sbin`, `/usr/bin` |
              | `services.msc`                     | system services + configuration files |
              | Registry                           |       Mostly text configuration files |
   
              **/**
              Root of everything. Contains the entire operating system hierarchy.

              Example:
              
              cd /
              ls

              Shows:

              bin
              boot
              dev
              etc
              home
              usr
              var       

              | Linux                                  | Linux                                                     | PostgreSQL                                      |
              | ------------------------------------:  | --------------------------------------------------------: | ----------------------------------------------: |
              | Single directory tree starting at `/`  |                                                           |                                                 |  
              | /bin                                   | Contains essential executable commands.                   |                                                 |
              | /sbin                                  | Contains system administration commands.                  |                                                 |
              | /etc                                   | Very important. Contains system configuration files.      |/etc/postgresql/ /etc/sysconfig/ /etc/systemd/   |  
              | /home                                  | Contains user directories.                                |                                                 |   
              | /root                                  | Home directory of Linux administrator.                    |                                                 |
              | /var                                   | Stores changing data.                                     | /var/log    /var/lib                            |
              | /tmp                                   | Temporary files.                                          | Do NOT store important backups here             |
              | /usr                                   | Contains installed applications and libraries.            |                                                 |
              | /opt                                   | Optional software installations.                          | Many organizations install PostgreSQL here.     |
              | /dev                                   | Contains device files. Linux treats devices as files.     |                                                 |
              | /proc                                  | Virtual filesystem showing running system information.    | Nothing actually stored here.                   |
              | /sys                                   | Provides hardware/kernel information.                     | Useful for troubleshooting.                     |
              | /boot                                  | Contains bootloader and kernel files.                     |                                                 |
              | /mnt                                   | Temporary mount location.                                 |                                                 |
              | /media                                 | Automatic mounting location                               |                                                 |
              | /run                                   | Stores temporary runtime information                      |                                                 |


           - Directories Most Important for a PostgreSQL DBA 

              | Directory |                        Why |
              | --------- | -------------------------: |
              | `/etc`    |   PostgreSQL configuration |
              | `/var`    |              Logs and data |
              | `/opt`    |    PostgreSQL installation |
              | `/home`   |                    Scripts |
              | `/tmp`    |       Temporary work files |
              | `/dev`    |            Storage devices |
              | `/proc`   | Memory/CPU troubleshooting |
              | `/run`    | Process/socket information |

           - Where PostgreSQL Commonly Stores Files

              | Component         |                Common location |
              | ----------------- | -----------------------------: |
              | Data files        |  `/var/lib/postgresql/16/main` |
              | Data files (RHEL) |       `/var/lib/pgsql/16/data` |
              | Config files      |      `/etc/postgresql/16/main` |
              | Logs              |          `/var/log/postgresql` |
              | WAL files         | `pg_wal` inside data directory |
              | Backups           |           `/backup/postgresql` |
              | Custom installs   |              `/opt/postgresql` |
